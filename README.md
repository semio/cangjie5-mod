# 优化仓颉键盘布局

在学习仓颉输入法的过程中我发现用仓颉打字打起來不是很顺手，从它的键位热力图也可以看出
分布不是特别合理。好在仓颉是单编码而且和英语字母的对应不是必要的，所以我们可以很容易
修改码表使它布局得更合理，或者适配不同的英语键盘布局。

本仓库的 remap_cangjie.py 是一个修改码表的脚本，它读取 mappings.tsv 里定义的英语和仓
颉字母对应关系，然后修改 rime-cangjie 中的码表和配置，使之符合你定义的键位。新的码表
和配置会放到本仓库的 build/ 目录里，把新文件拷贝到 RIME 目录即可。

脚本由 glm-5.3-flash 写成。

注：修改完必需清除原本的用户词库 （userdb 目录、sync目录）然后重新部署 RIME。
